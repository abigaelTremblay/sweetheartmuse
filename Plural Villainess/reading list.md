# Plural Villainess: Reading List (Real-World References)

These are the real-world sources the story borrows from, with each pointer kept narrow. Within each tier, entries run from most to least relevant. Cross-references point to `characters.md` and `worldbuilding.md`. Links are given only where a free, stable source is worth the click. Times are rough estimates.
